About

Vault is a static, client-side password manager. Entries are encrypted with AES-GCM using a key derived from your master password via PBKDF2, and the encrypted data never leaves this browser. Optional passkey unlock uses your device's fingerprint, face, or PIN via WebAuthn — Vault never sees or stores biometric data, your master password, or a private key. Vault is a portfolio/demo project and has not undergone professional security auditing — it should not be treated as equivalent to an audited, production password manager.
